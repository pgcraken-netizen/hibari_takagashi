# 高橋先生とあそぼう！ ― 今日は先生、なに着てる？

特別な支援を必要とする子どもたちが、スマホで気軽に遊びながら高橋先生と出会える、やさしい着せ替えコレクションゲーム（MVP）。

## できること

- **ホーム**：今日の先生（毎日ちがう帽子・衣装・小物）、今日のひとこと、季節の背景、「今日のテーブル」（タップで「いただきます！」）
- **先生をおまかせ！／もう一回！**：衣装・帽子・小物・背景をまとめておまかせ
- **きせかえ**：帽子（9カテゴリ＋おきにいり、おすすめ3つ）、衣装10種、小物10種
- **ぼうしずかん**：帽子110種。未発見はシルエット表示
- **高橋先生カード**：帽子の数に応じて12枚が解放
- **きせつのへや**：春夏秋冬の背景・テーブル・季節の帽子
- **先生について**：子ども向けの短い紹介＋大人向けに公式サイトへのリンク
- **せってい**：声／音声であそぶ／効果音／BGM／振動／アニメーション／文字を大きく

ゲームオーバー・タイマー・ランキング・課金・広告・ユーザー登録はありません。記録は端末内（localStorage）のみ。

### 帽子が集まるしくみ（ガチャにしない）

- 毎日最初に開くと、まだ持っていない帽子が1つ届く
- きせかえの「ぼうしばこ🎁」をあけると必ず新しい帽子
- おまかせは3回に1回は必ず新しい帽子（救済）
- テーブルの食べ物を4回食べると「ごちそうさまのおれい」

## 絵について

### ゲーム画面（ホーム）
- 参考画像 `scripts/art/home-ref.png` から、部屋・先生・テーブル・料理・ボタン・ヘッダー・ナビを切り出しています（`scripts/art/build_home.py`）。
- 先生がいた場所や料理の下は、LaMa（big-lama）で自然に埋めています（`scripts/art/lama.py`）。必要なもの：PyTorch と重み `big-lama.pt`。
- 夏・秋・冬の部屋は、春の部屋の窓の外と飾りの色を変えて作っています。
- 衣装は、先生の白衣の陰影を残したまま色を塗り替えています（`scripts/art/outfits_home.py`）。
- 帽子は `scripts/art/plushify.py` でフェルトのように立体的に見せています（`public/art/hat3d`）。ひまわりの帽子は、参考画像のものをそのまま使っています。

### タイトル・その他

- **タイトル画面**：キービジュアル（`scripts/art/keyvisual.png`）をそのまま使い、ボタンの位置にタップ領域を重ねています。
- **高橋先生**：キービジュアルから顔と手を切り出しています（`scripts/art/extract_sensei.py`）。その上に、帽子と衣装の絵を重ねています。
- **部屋・テーブル・ごはん・衣装・帽子（110）・アイコン**：`scripts/art/studio.html` で、クレヨンと水彩のタッチ（SVGフィルター）で描いています。モチーフには Noto Emoji のベクター（Apache-2.0）を、フェルトや水彩風に加工して使っています。
- **書き出し**：`python3 scripts/art/render.py`（全部）／`python3 scripts/art/render.py hat_ --missing`（足りない分だけ）。先にデータを書き出しておきます：`node --experimental-strip-types scripts/art/export-data.mjs`。
- **ほんものの先生カード**：写真2枚（`public/art/photo-*.jpg`）。同じ帽子を見つけると、そのカードがひらきます。

## 技術

Next.js（App Router）／React／TypeScript／Tailwind CSS v4／PWA（manifest + service worker）／Vercel

```
src/data/hats.ts      帽子（110）
src/data/outfits.ts   衣装（10）
src/data/content.ts   小物・ひとこと・リアクション・カード・公式リンク
src/data/seasons.ts   季節（背景色・テーブル・季節のもの）
src/components/Sensei.tsx  先生キャラ（SVG。帽子・衣装・表情8種）
src/components/Stage.tsx   背景＋先生＋ふきだし＋テーブル
src/components/GameApp.tsx 画面と遊びのロジック
```

帽子の追加は `hats.ts` に1行足すだけです（絵文字モチーフ＋スタイル `cap / trio / big / tall`）。

- 先生の名前・肩書き・カード文章・「先生について」の内容 → **本人・うりずんの確認**
- 実在施設（うりずん・ひばりクリニック）をモチーフにした帽子・名称 → 利用許諾
